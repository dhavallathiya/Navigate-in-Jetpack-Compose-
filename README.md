# How to Navigate and Pass Data from One Screen to Another in Jetpack Compose 🚀 | Android Studio

## Overview
This project provides a comprehensive guide on how to navigate between screens and pass data from one screen to another using Jetpack Compose, the modern toolkit for building native Android UIs.

## Features
- Step-by-step instructions on navigation in Jetpack Compose
- Examples of passing data between screens
- Clear code samples and explanations

## Getting Started
To get a local copy up and running, follow these simple steps.

### Prerequisites
- Android Studio installed
- Basic knowledge of Kotlin and Jetpack Compose
